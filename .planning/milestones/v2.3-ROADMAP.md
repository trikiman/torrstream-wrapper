# Roadmap (Archived): TorrStream v2.3 Lampa parser shim

**Shipped:** 2026-05-22
**Phases:** 1
**Plans:** 1

## Overview

Single-phase milestone fixing a real user-blocking issue: plain `http://jac.red`
and selectively `https://jac.red` getting blocked/throttled by the user's ISP
killed Lampa torrent search. Workaround (manually flipping `jackett_url`
between mirrors) was fragile.

Robust fix: TorrStream wrapper exposes both `/api/v1.0/torrents` (jacred path)
and `/api/v2.0/indexers/all/results` (Jackett path) that proxy to the configured
`JACRED_URL`. Lampa points at `https://tv.trikiman.shop` once. Survives any
mirror change because Oracle Amsterdam reaches all jacred mirrors and the
wrapper's env var is the only knob ops needs.

## Phases

- [x] **Phase 1: Lampa parser shim** — `/api/v1.0/torrents` + `/api/v2.0/indexers/all/results` proxy with CORS, Lampa client switched to use TorrStream as parser. (completed 2026-05-22)

## Phase 1 Details

**Goal**: TorrStream serves as a Lampa-compatible torrent parser. Lampa points at `https://tv.trikiman.shop`, search renders results unchanged.

**Requirements**: [LAMPA-01, LAMPA-02]

**Success Criteria (delivered):**
1. ✓ `GET /api/v1.0/torrents?search=Matrix` returns raw jacred response (flat array of records). 731 KB body, 730 results live.
2. ✓ `GET /api/v2.0/indexers/all/results?Query=Matrix` returns Jackett-shape `{Results:[...]}`. 2553 bytes, real Russian-release results.
3. ✓ All query params forwarded unchanged (search, Query, title, title_original, year, is_serial, genres, apikey).
4. ✓ CORS headers permit cross-origin fetch from any Lampa origin.
5. ✓ Returns 502 + `{}` on upstream failure (Lampa shows "no results" instead of parser error).
6. ✓ `JACRED_URL` env var lets ops swap mirrors without code changes.
7. ✓ Lampa switched: `jackett_url: https://tv.trikiman.shop`. Matrix search → 20 torrent rows live.
